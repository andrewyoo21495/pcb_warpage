1. 프로젝트 개요

본 프로젝트는 PCB(인쇄회로기판) 설계 이미지로부터 워피지(warpage)/높이(elevation) 패턴을 조건부로 생성하는 딥러닝 프레임워크입니다. 하나의 설계 이미지가 주어지면, 모델은 해당 설계에서 나타날 수 있는 다양한 변형(elevation) 패턴을 확률적으로 생성합니다.

핵심 특징

  • 3가지 생성 모델을 통합된 인터페이스로 지원: CVAE, LDM, LFM
  • Leave-one-out 검증: 10개 설계(A~J) 중 1개를 테스트, 9개로 학습
  • Config-driven: 모든 하이퍼파라미터를 텍스트 설정 파일로 관리
  • 2단계 구조: LDM과 LFM은 사전 학습된 CVAE를 동결(freeze)하고, 64차원 잠재 공간에서 새로운 네트워크만 학습

2. 전체 시스템 아키텍처

세 모델 모두 동일한 통합 API를 노출합니다. build_model(config) 팩토리 함수가 설정 파일의 model_type에 따라 적절한 클래스를 인스턴스화합니다. 

# 팩토리 패턴 (models/__init__.py)
model = build_model(config)          # 'cvae' | 'ldm' | 'lfm'

# 학습
loss = model(elevation, design, hand_features)

# 추론 (공통 인터페이스)
samples = model.sample(design, hand_features, num_samples=K, temperature=1.0)
# → (K, 1, 256, 256)  ∈ [0, 1]

그림 2-1. 통합 추론 파이프라인 — 모델 종류에 관계없이 Design → c, 잠재 공간 생성 → Decoder → Elevation 이미지

3. 공유 컴포넌트 ① — Design Encoder

DesignEncoder는 설계 이미지와 수공 특징(handcrafted features)을 결합하여 64차원 조건 벡터 c를 생성합니다. 세 모델 모두 동일한 인코더를 사용합니다.

그림 3-1. Design Encoder — CNN 브랜치(이미지)와 Hand Features 브랜치를 Fusion MLP로 결합하여 조건 벡터 c 생성

핵심 설계 결정

  • 4×4 Spatial Pooling: 1×1이 아닌 4×4로 풀링하여 설계 이미지의 공간적 레이아웃 정보를 보존
  • Feature Selection: selected_features 설정으로 24개 수공 특징 중 유의미한 부분집합만 선택 가능
  • Dropout (p=0.3): 10개 설계만으로 학습하므로 과적합 방지를 위해 적극적인 정규화 적용
  • 소형 설계: 소수의 학습 설계를 암기하지 않도록 의도적으로 작은 네트워크 사용

4. 공유 컴포넌트 ② — Elevation Encoder

ElevationEncoder는 실제 elevation 이미지를 받아 확률적 잠재 벡터 z₁을 생성합니다. VAE의 인코더 역할을 하며, 평균(μ)과 로그 분산(logvar)을 출력합니다. 학습 시에만 사용되며, LDM/LFM에서는 동결 상태로 잠재 표현 z₀ = μ를 추출하는 데 쓰입니다.

그림 4-1. Elevation Encoder — CNN으로 이미지를 압축 후, μ/logvar 두 헤드로 분리하여 Reparameterization Trick 적용

Logvar Clamping

logvar는 [logvar_clamp_min, logvar_clamp_max] 범위로 클램핑됩니다 (기본값: [−6.0, 4.0]). 넓은 범위를 허용함으로써 posterior collapse를 방지하고, 더 표현력 있는 사후 분포를 학습할 수 있습니다.

5. 공유 컴포넌트 ③ — Decoder (FiLM)

Decoder는 융합된 잠재 벡터 z_fused를 256×256 elevation 이미지로 복원합니다. 초반 레이어는 조건 없이(PlainBlock), 후반 레이어는 조건 벡터 c로 변조하여(FiLMBlock) coarse-to-fine 생성을 구현합니다.

그림 5-1. Decoder — 초반 PlainBlock(조건 독립)으로 전체 구조, 후반 FiLMBlock(조건 의존)으로 세부 패턴 생성

FiLM Layer 작동 원리

Feature-wise Linear Modulation은 조건 벡터 c로부터 채널별 scale(γ)과 shift(β)를 생성하여 특징 맵을 변조합니다:

γ = linear_γ(c).unsqueeze(-1).unsqueeze(-1)  # (B, C, 1, 1)
β = linear_β(c).unsqueeze(-1).unsqueeze(-1)  # (B, C, 1, 1)
output = γ * x + β                           # 채널별 아핀 변환

Coarse-to-Fine 설계 이유

  • PlainBlock (초반): z₁만으로 전체적인 elevation 구조를 생성하도록 강제 → 잠재 공간이 의미 있는 정보를 인코딩
  • FiLMBlock (후반): 설계 조건 c가 고해상도 세부 패턴만 조절 → 모델이 설계-의존적 미세 변형을 학습

6. 공유 컴포넌트 ④ — Latent Denoiser / Velocity Net

LatentDenoiser는 LDM과 LFM 모두에서 사용되는 MLP 기반 네트워크입니다. LDM에서는 노이즈 예측기(ε̂), LFM에서는 속도장 예측기(v̂)로 작동하며, 동일한 AdaLN(Adaptive Layer Norm) ResBlock 아키텍처를 공유합니다.

그림 6-1. Latent Denoiser/VelocityNet — Sinusoidal 시간 임베딩 + AdaLN ResBlock 스택으로 노이즈(LDM) 또는 속도(LFM) 예측

AdaLN (Adaptive Layer Normalization)

일반 Layer Normalization에 시간 조건(t_emb)에서 파생된 scale(s)과 shift(b)를 적용합니다. DiT(Diffusion Transformer)에서 영감을 받은 기법으로, 시간 정보를 각 블록에 효과적으로 주입합니다. 

# AdaLN 조건 파라미터 생성 (4 × hidden_dim)
params = adaLN_linear(t_emb)           # (B, 4H)
s1, b1, s2, b2 = params.chunk(4, -1)  # 각 (B, H)

# 첫 번째 sub-layer
h = norm1(x) * (1 + s1) + b1
h = fc1(SiLU(h))

# 두 번째 sub-layer
h = norm2(h) * (1 + s2) + b2
h = fc2(SiLU(h))

return x + h  # 잔차 연결
Zero Initialization: 최종 출력 Linear의 가중치를 0으로 초기화합니다. 학습 초기에 블록이 항등 함수처럼 작동하여 안정적인 학습 시작을 보장합니다.

7. 모델 A — CVAE (Conditional VAE)

CVAE는 독립적으로 학습되는 baseline 모델입니다. 동시에 LDM과 LFM의 사전 학습 백본으로도 사용됩니다. Elevation Encoder, Design Encoder, Fusion, Decoder를 모두 end-to-end로 학습합니다.

7.1 학습 흐름

그림 7-1. CVAE 학습 흐름 — Elevation Encoder와 Design Encoder가 각각 z₁, c를 생성하고, Fusion 후 Decoder가 복원

7.2 Fusion 방식 비교

방식수식출력 차원특징
Concat z_fused = [z₁; c] z_dim + c_dim = 128 단순 연결; Decoder가 공동 표현 학습
FiLM (기본) z_fused = γ(c) × z₁ + β(c) z_dim = 64 조건이 잠재 벡터를 아핀 변환; 더 컴팩트
Cross-Attention z_fused = Attn(Q=c, K=z₁, V=z₁) z_dim = 64 z₁을 4개 토큰으로 분리, 4-head attention

7.3 KL Annealing (순환 가열)

학습 초기에 β=0으로 시작하여 Decoder가 먼저 구조를 학습하고, 점진적으로 β를 증가시켜 Encoder가 정보를 압축하도록 유도합니다. 이 과정을 여러 주기(기본 8회)로 반복합니다. 

def get_cyclical_beta(epoch, total_epochs, beta_max, n_cycles):
    cycle_len = total_epochs / n_cycles
    pos_in_cycle = epoch % cycle_len
    return beta_max * (pos_in_cycle / cycle_len)

8. 모델 B — LDM (Latent Diffusion Model)

LDM은 2단계 모델입니다. 1단계에서 사전 학습된 CVAE를 동결하고, 2단계에서 CVAE의 64차원 잠재 공간 내에서 확산(diffusion) 과정을 학습합니다. 픽셀 공간이 아닌 저차원 잠재 공간에서 확산을 수행하므로 계산 효율이 높습니다.

8.1 2단계 구조

그림 8-1. LDM 학습(위)과 DDIM 추론(아래) — 64차원 잠재 공간에서 확산/역확산 수행

8.2 Cosine Noise Schedule

LDM은 선형이 아닌 cosine 스케줄을 사용하여 ᾱ_t를 정의합니다. Cosine 스케줄은 학습 초반(t가 작을 때)에 노이즈를 천천히 추가하여 저주파 구조를 더 잘 보존합니다.

8.3 학습 가능 파라미터

Elevation EncoderFrozen~2.1M (학습 안 함)
Design EncoderFrozen (기본) / Trainable~100K
DecoderFrozen~1.5M (학습 안 함)
Latent DenoiserTrainable~4.2M
EMA (Exponential Moving Average): LDM은 학습 중 EMA(decay=0.9999)를 적용하여 추론 시 안정적인 가중치를 사용합니다. 체크포인트에 ema_state_dict로 저장됩니다.

9. 모델 C — LFM (Latent Flow Matching)

LFM은 LDM과 동일한 2단계 구조를 사용하지만, 확산 대신 최적 수송(Optimal Transport) 기반 흐름 매칭을 사용합니다. 노이즈 스케줄이 필요 없고, 직선 경로를 따라 ODE를 적분하므로 더 단순하고 효율적입니다.

12. 평가 프로토콜

12.1 Leave-One-Out 검증

10개 설계(A~J) 중 1개를 held-out 테스트 세트로 사용하고, 나머지 9개로 학습합니다. 이 과정을 10번 반복(fold 0~9)하여 모든 설계에 대한 일반화 성능을 측정합니다.

12.2 평가 지표

지표대상수식해석
Reconstruction MSE CVAE only MSE(reconstruct(x), x) < 0.005: 우수 / < 0.01: 양호
Sample Diversity 모든 모델 Var(samples) 픽셀별 분산의 평균 real diversity의 0.3~3.0배가 적절
MMD 모든 모델 K_rr + K_gg − 2K_rg (RBF kernel) < 0.1: 우수 / 0.1~0.3: 보통 / > 0.3: 부족
Active KL dims CVAE only count(mean_KL_per_dim > 0.1) > z_dim/4: 건강한 잠재 공간

12.3 2단계 검증

  • Step 1 — 암기 검증 (학습 분할): Train Recon MSE, Real Diversity 측정. 학습 데이터를 제대로 학습했는지 확인.
  • Step 2 — 일반화 검증 (Held-out 분할): Val Recon MSE, Gen Diversity, MMD, Active KL dims 측정. 보지 못한 설계에 대한 성능 평가.
